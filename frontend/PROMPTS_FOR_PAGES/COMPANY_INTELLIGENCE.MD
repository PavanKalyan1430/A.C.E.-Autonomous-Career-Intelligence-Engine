============================================================

LIVE STATE

============================================================



When searching:



● Researching Google...



Then:



✓ Intelligence updated



Use cyan for the live state.



Do not create a large animated loading screen.



============================================================

TECH STACK

============================================================



Display detected technologies as restrained tags.



Example:



Go

C++

gRPC

Envoy

Kubernetes



No random colors per technology.



Use ACE blue-family styling.



============================================================

HIRING SIGNALS

============================================================



Show concise hiring insights.



Do not create unsupported numeric statistics.



Only display information returned by backend research.



============================================================

INTERVIEW PROCESS

============================================================



Show known/interpreted stages.



Make each stage clickable if detailed information exists.



============================================================

ACE ANALYSIS

============================================================



This is where company intelligence connects back to the candidate.



Show:



Your alignment

Skill gaps

Recommended preparation



Actions:



Compare Resume

Prepare Interview

View Skill Roadmap

Ask ACE

SOURCE TRANSPARENCY
